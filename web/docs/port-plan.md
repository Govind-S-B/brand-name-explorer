# Static port checkpoints

The Python CLI is the reference and remains byte-for-byte unchanged. Build and
verify locally only; no repository, remote, push, or publication is part of this work.

1. Browser throughput spike: real headless installed Chrome, CDP protocols and
   socket overlap, desktop and throttled mobile emulation, RDAP/DoH concurrency
   sweeps, gating vs idle-slot hedging, and split-provider comparisons.
2. Pure TypeScript parity: Python-compatible integer-seeded MT19937, weighted
   grammar and original presets, pronunciation, inverse fitting, reverse reports,
   and substitutions. Generate fixtures directly from the unchanged Python code.
3. Worker and storage: independent bounded provider queues, retries without
   occupying request slots, ordered output, IDB results and resumable session
   cursors, refresh boundaries, foreground resume, and portable shortlist export.
4. Mobile-first interface: generate immediately without a network dependency;
   mood / Generate / results always visible, folded controls, separate analysis
   tools, advanced tuning and cache/export.
5. Offline and load: content-hashed Vite assets, generated scoped service-worker
   precache, dictionary loaded only for analysis features, relative paths,
   production-preview mobile metrics, screenshots, keyboard and offline checks.

Evidence is stored under web/docs. Browser emulation is not physical iOS testing.
