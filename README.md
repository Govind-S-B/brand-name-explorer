# brand name explorer

sound-symbolism based untaken brand name discovery tool 
  
making up brand names based on how they sound and feel, with a .com check to filter some out

# usage

[open the web app](https://govind-s-b.github.io/brand-name-explorer/) every time u reload the page u get a new set of words to work with

but the fun part is when u explore surrounding words and reverse search, and use those to find interesting ones
  
make sure u collect the good ones, you blink and you miss

# motivation

i always used to struggle coming up with good brand names but had a friend who did it effortlessly. he just spews random words and they sound nice. i came across the old [bouba/kiki experiment](https://en.wikipedia.org/wiki/Bouba/kiki_effect) and experimented with a few moods based on it. i think brand names need not be meaningful real words always, you can totally make a new word and associate a new meaning to it.

i set a few rules for how i want the sounds to be, then generate a sample i can quickly skim through.

to make it faster, i pair it with a TLD search to quickly filter some if i want to explore unique names.
